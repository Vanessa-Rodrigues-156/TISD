# How to Use

This project contains Python files, datasets, and various versions of Sthira organized into folders.

## Python Files
The Python files in this project are the core scripts for running and interacting with the LLM systems. To use them:
1. Ensure you have Python installed on your system.
2. Install any required dependencies listed in the `requirements.txt` file (if available) using:
    ```bash
    pip install -r requirements.txt
    ```
3. Run the desired Python script using:
    ```bash
    python <script_name>.py
    ```

## Datasets
The `datasets` folders contain all the datasets required for this project. Ensure these folders are in the correct directory structure before running the scripts.

## Sthira Versions
Each folder represents a specific version of the Sthira framework. Use the scripts and files within the respective folders as per your requirements.








For further details, refer to the documentation or comments within the scripts.
